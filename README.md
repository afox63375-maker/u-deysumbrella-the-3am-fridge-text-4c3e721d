# The 3AM Fridge Text

The message a smart fridge texts its owner at 3am — not a complaint
about milk or a door left open, but a night-shift report from the one
appliance that never clocks out. The house is asleep, the light is on,
the hum is steady, and somebody has to watch the dark all night. The
fridge would like it noted that it is doing exactly that, and that no
one has thanked it yet.

## Run it

```sh
python3 main.py
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), with no trailing newline.
